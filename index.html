📗 Your Google Sheet Not linked

Sign in with your own Google account. CASHFLOW creates a private sheet named "CASHFLOW Data" in your Google Drive and saves every change there automatically, plus a daily backup file in the "CASHFLOW Backups" folder (last 30 days kept). Nobody else can see it.

💾 Local backup

Your data is saved in this browser. Take a backup file regularly so nothing is lost.

🛠 Advanced: link via Apps Script

Every user links their own Google Sheet. Your accounts and transactions appear there as tables, and the same data opens on phone and PC.

Apps Script setup code

  1. Create a new Google Sheet (sheets.new) → Extensions → Apps Script → delete old code, paste the code below.
  2. Change MY_SECRET_KEY to your own password.
  3. Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone.
  4. Copy the Web App URL and paste it above with the same secret key.
